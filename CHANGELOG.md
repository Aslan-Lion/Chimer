# Changelog

All notable releases of Chimer are documented here.

## [0.1.0] - Initial release

- Dual-window timer interface.
- Separate presentation display with external monitor support.
- Timer and session management.
- Presets and multi-stage sessions.
- Customizable presentation layouts and appearance.
- Local-network device pairing and remote controls.
- Device permissions and pairing management.

### Security and availability notes

- Remote control is intended for trusted local networks.
- The local WebSocket connection is not transport-encrypted.
- Online relay networking and end-to-end encryption are not included.
